Archive Status

Temporary public mirror: this GitHub Pages site reconstructs the recovered MANTA wiki, including its pages, legacy wiki images, installation video, documentation and example downloads.

Software archives

The Downloads & Installation page links to preserved 2024 application packages stored as GitHub Release assets. These are the newest matching archived packages recovered from the original software download inventories; they should not be interpreted as newer 2026 releases.

Preservation

The original recovered Git wiki history and a separate NAS archival copy are retained outside this public mirror. This site is intended as a temporary replacement while a longer-term institutional home is determined.

Analytics and privacy

This site uses Google Analytics 4 to understand aggregate site usage and help improve the MANTA documentation. Google may receive technical information about visits in accordance with Google's privacy practices. This static MANTA site does not require a user account or login.
